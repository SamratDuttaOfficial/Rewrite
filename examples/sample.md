# Why small models matter

In recent years, a large number of companies have started to rely on huge language models. However, these models are expensive to run, and they send your data to someone else's servers.

Small models that run on your own computer are a good alternative. They are fast, private, and they work without an internet connection. For example, a model with 100 million parameters can easily run on a laptop.

## Getting started

Install the package with `pip install something` and read the [documentation](https://example.com/docs) in order to understand the options.

```python
# code blocks are never changed
model = load("small-model")
```

It is important to note that small models are not perfect. They make mistakes, so you should always check the results carefully.
