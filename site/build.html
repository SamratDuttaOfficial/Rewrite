Build it yourself

Make an installer for .

Rewrite is written in Rust with GTK 4. If you have a machine with this system, these steps build an installer. Then send it in, and once it is checked it is listed here for everyone.

  1. Install the tools. Rust from rustup.rs and GTK 4's development files: 
    2. 
        
  2. Get the source of the latest release.
          
    git clone https://github.com/SamratDuttaOfficial/rewrite
cd rewrite
git checkout $(git describe --tags --abbrev=0)
    3. 
        
  3. Check that it runs. The first run downloads ONNX Runtime and PDFium for your system.
          
    cargo xtask run
    4. 
        
  4. Build the installer. It lands in dist/installers/. Expected name:
          
    
          
    cargo xtask package
    
          If cargo xtask package does not support your system yet, a pull request that adds it is just
          as welcome as the build.
    5. 
        
  5. Publish the file. Fork the repository on GitHub, create a release in your fork, and
          attach the installer. Note its SHA-256:
          
    sha256sum dist/installers/*      # Linux
shasum -a 256 dist/installers/*  # macOS
certutil -hashfile FILE SHA256   # Windows
    6. 
        
  6. Send it in. Fill in the form with the download link, the SHA-256 and the commands you
          used. After it is checked it appears on this page and on the download list.
          
    Submit your build
    7. 
      

      
Please build from an unmodified release tag. Builds that change the code, bundle extra
        software or cannot be reproduced from the steps given are not approved.
