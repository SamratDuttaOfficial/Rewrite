Build it and send it in

There is no official installer for yet. If you have one of these machines, you can make it. Once your build is checked, it is listed on this page and in the download list for everyone.

  1. Install Rust and GTK 4. Rust comes from rustup.rs. 
    2. 
        
  2. Get the source of the latest release.
          
    git clone https://github.com/SamratDuttaOfficial/rewrite
cd rewrite
git checkout $(git describe --tags --abbrev=0)
    3. 
        
  3. Run it once. The first run downloads ONNX Runtime and PDFium for your system.
          
    cargo xtask run
    4. 
        
  4. Build the installer. It is written to dist/installers/, named like
          .
          
    cargo xtask package
    
          If the build script does not know your system yet, a pull request that teaches it is as welcome as the build.
    5. 
        
  5. Put the file online. Fork the repository on GitHub, make a release in your fork and attach the
          installer. Then note its SHA-256:
          
    sha256sum FILE              (Linux)
shasum -a 256 FILE          (macOS)
certutil -hashfile FILE SHA256   (Windows)
    6. 
        
  6. Send it in. The form asks for the link, the SHA-256 and the commands you used.
          
    Send in a build
    7. 
      

      
Build from an unmodified release. Builds that change the code, add other software or cannot be
        repeated from the steps given are not listed.
