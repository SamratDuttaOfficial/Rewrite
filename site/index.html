Open the files you already have

The same suggestions work in every kind of document, and the formatting stays as it was.

Word and OpenDocument

Open and save .docx, .doc, .odt, .fodt and .rtf with styles, lists, tables, pictures, charts, formulas and footnotes. A formatting toolbar covers the everyday edits.

  • Export to PDF, HTML, Markdown or LaTeX
  • Saving .doc uses LibreOffice if it is installed

LaTeX and Markdown

LaTeX on the left, the typeset PDF on the right, built with your own TeX installation. Markdown gets a live preview. Commands, equations, citations and code are never rewritten.

  • F5 rebuilds the preview
  • Works with MiKTeX, MacTeX and TeX Live

PDF

Highlight, underline, strike out, add notes, draw, white out, add text and pictures, and change a line of text in place. Rotate, move, delete, insert or merge pages.

  • Turn a PDF into an editable document
  • No Acrobat licence needed

Rewrite a whole document

Auto-rewrite goes through a selection or the whole file. Apply every change, or step through them and accept or reject each one against the original.

  • Light, medium or strong
  • Whole-sentence paraphrasing can be turned on or off

Light and dark

One click switches the theme. Text size, fonts and panels can be set to taste.

Questions

Is it free?

Yes, with no trial and no account. The source is on GitHub under the MIT licence with the Commons Clause: use and change it freely, keep the credit when you reuse it, and do not sell it.

Does my text leave the computer?

No. The models run on your processor. The only download is the one-time model download of about 400 MB, and you can skip it and use the built-in thesaurus instead.

Do I need a graphics card?

No. An ordinary laptop is enough.

Windows warns about an unknown publisher.

The installer is not code-signed yet. Choose "More info", then "Run anyway". On a Mac, right-click the app and choose Open the first time.

Will it break my LaTeX or Markdown?

No. Only the prose is rewritten; commands, maths, citations, links and code are left alone.

My system is not in the list.

Pick its row anyway. It leads to the build steps and a form to send your build in, so others with the same system can download it.
